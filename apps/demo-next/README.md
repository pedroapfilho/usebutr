# demo-next

A nextjs reference that exercises butr discovery, connection state, persistence, and React hooks.

From the repository root (Node 24+, pnpm 11.13.1, and trusted Portless):

```bash
pnpm install && pnpm build --filter="./packages/*" && pnpm dev --filter=demo-next
```

Open `https://usebutr.demo-next.localhost`. Worktrees add a branch prefix; use the printed URL.
See the [guide](https://docs.usebutr.com/getting-started/frameworks/nextjs) and [contribution setup](../../CONTRIBUTING.md).
