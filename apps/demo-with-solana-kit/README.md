# demo-with-solana-kit

Connect wallets with butr and use solana-kit for chain operations on testnets.

From the repository root (Node 24+, pnpm 11.13.1, and trusted Portless):

```bash
pnpm install && pnpm build --filter="./packages/*" && pnpm dev --filter=demo-with-solana-kit
```

Open `https://usebutr.demo-with-solana-kit.localhost`. Worktrees add a branch prefix; use the printed URL.
See the [guide](https://docs.usebutr.com/integrations/solana-kit) and [contribution setup](../../CONTRIBUTING.md).
