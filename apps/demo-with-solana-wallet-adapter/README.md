# demo-with-solana-wallet-adapter

Connect wallets with butr and use solana-wallet-adapter for chain operations on testnets.

From the repository root (Node 24+, pnpm 11.13.1, and trusted Portless):

```bash
pnpm install && pnpm build --filter="./packages/*" && pnpm dev --filter=demo-with-solana-wallet-adapter
```

Open `https://usebutr.demo-with-solana-wallet-adapter.localhost`. Worktrees add a branch prefix; use the printed URL.
See the [guide](https://docs.usebutr.com/integrations/solana-wallet-adapter) and [contribution setup](../../CONTRIBUTING.md).
