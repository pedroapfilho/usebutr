# demo-with-solana-web3js

Connect wallets with butr and use solana-web3js for chain operations on testnets.

From the repository root (Node 24+, pnpm 11.13.1, and trusted Portless):

```bash
pnpm install && pnpm build --filter="./packages/*" && pnpm dev --filter=demo-with-solana-web3js
```

Open `https://usebutr.demo-with-solana-web3js.localhost`. Worktrees add a branch prefix; use the printed URL.
See the [guide](https://docs.usebutr.com/integrations/solana-web3js) and [contribution setup](../../CONTRIBUTING.md).
