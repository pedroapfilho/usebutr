# demo-with-sui

Connect wallets with butr and use sui for chain operations on testnets.

From the repository root (Node 24+, pnpm 11.13.1, and trusted Portless):

```bash
pnpm install && pnpm build --filter="./packages/*" && pnpm dev --filter=demo-with-sui
```

Open `https://usebutr.demo-with-sui.localhost`. Worktrees add a branch prefix; use the printed URL.
See the [guide](https://docs.usebutr.com/integrations/sui) and [contribution setup](../../CONTRIBUTING.md).
