# demo-with-viem

Connect wallets with butr and use viem for chain operations on testnets.

From the repository root (Node 24+, pnpm 11.13.1, and trusted Portless):

```bash
pnpm install && pnpm build --filter="./packages/*" && pnpm dev --filter=demo-with-viem
```

Open `https://usebutr.demo-with-viem.localhost`. Worktrees add a branch prefix; use the printed URL.
See the [guide](https://docs.usebutr.com/integrations/viem) and [contribution setup](../../CONTRIBUTING.md).
