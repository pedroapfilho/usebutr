# demo-with-wagmi

Connect wallets with butr and use wagmi for chain operations on testnets.

From the repository root (Node 24+, pnpm 11.13.1, and trusted Portless):

```bash
pnpm install && pnpm build --filter="./packages/*" && pnpm dev --filter=demo-with-wagmi
```

Open `https://usebutr.demo-with-wagmi.localhost`. Worktrees add a branch prefix; use the printed URL.
See the [guide](https://docs.usebutr.com/integrations/wagmi) and [contribution setup](../../CONTRIBUTING.md).
