## Signer kinds

`getSigner()` resolves a `WalletSigner`, a union tagged by `kind`. Each
transport package registers its own variant, so a kind is part of the union
once its package is part of your program. `@usebutr/wallets` loads every
platform package, so an app that imports only it can narrow every browser
wallet's kind; WalletConnect and Ledger kinds come with their packages.

| `kind`                                                     | Fields                                               | Registered by                     |
| ---------------------------------------------------------- | ---------------------------------------------------- | --------------------------------- |
| `eip1193`                                                  | `provider: Eip1193Provider`                          | `@usebutr/evm`                    |
| `wallet-standard`                                          | `wallet: WalletStandardWallet`                       | `@usebutr/wallet-standard-shared` |
| `unisat`, `sats-connect`                                   | `provider`                                           | `@usebutr/bitcoin`                |
| `polkadot-injected`                                        | `extension`, `extensionName: string`                 | `@usebutr/polkadot`               |
| `walletconnect`                                            | `chainId: string`, `provider: UniversalProviderLike` | `@usebutr/walletconnect`          |
| `ledger-evm`, `ledger-svm`, `ledger-sui`, `ledger-bitcoin` | `app`: the device app                                | `@usebutr/ledger`                 |

Which connector yields which kind is on each
[connector page](/connectors).
