The layer `@usebutr/svm`, `@usebutr/sui`, `@usebutr/bitcoin` and
`@usebutr/polkadot` build on. App code usually needs only `getFeature` and
`findAccount`; the rest is for adapter authors. No React dependency.

```npm
npm install @usebutr/wallet-standard-shared @wallet-standard/app zustand
```

`@wallet-standard/app` is an optional peer in the manifest, but the default
discovery loader needs it; a custom loader can supply a registry for tests.
`@usebutr/wallets` installs it for you.

## Signer

Importing the package registers the `wallet-standard` signer kind, so every
adapter built on it resolves `getSigner()` to
`{ kind: "wallet-standard", wallet: WalletStandardWallet }`.

## Features

### `getFeature<Feature>(wallet, name, method): (WalletStandardFeature & Feature) | undefined`

The spec keys `features` by name with no fixed shape, so the caller names the
feature type and the method that proves it. `undefined` when the wallet does
not advertise the feature or the method is missing. No cast needed:

```ts
import type { SolanaSignMessageFeature } from "@usebutr/svm";
import { findAccount, getFeature } from "@usebutr/wallet-standard-shared";

const signer = await wallet.connector.getSigner();
if (signer.kind === "wallet-standard") {
  const feature = getFeature<SolanaSignMessageFeature>(
    signer.wallet,
    "solana:signMessage",
    "signMessage",
  );
  const account = findAccount(signer.wallet.accounts, wallet.account.walletAddress);
  if (feature && account) {
    const [output] = await feature.signMessage({ account, message });
  }
}
```

The returned feature is the wallet's own object, so its methods keep their
`this`.

### `findAccount(accounts, address): WalletStandardWalletAccount | undefined`

The Wallet Standard account for a butr address. `undefined` for an address
the wallet does not expose, never another account in its place.

## Adapter authoring

### `slugify(platformPrefix, name): string`

`wallet-standard:<prefix>-<slug>`, e.g. `slugify("svm", "Phantom")` is
`wallet-standard:svm-phantom`. The prefix gives a multi-chain wallet one id
per platform.

### `createWalletStandardCore(input): WalletStandardCore | null`

The members every Wallet Standard adapter shares. `null` when the wallet
advertises no chain in `input.namespace` or lacks `standard:connect`.

`WalletStandardCoreInput`: `chains` (the platform's registry, for names),
`id`, `label` (`"Solana"`, for errors), `namespace` (`"solana"`),
`preferredChainIds`, `registerDisconnector?`, `trackChainChanges`, `wallet`.

`WalletStandardCore`:

| Member                     | Notes                                                                                                                                                                 |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `base`                     | Spread into the adapter: `connect`, `getAccounts`, `getSigner`, `icon`, `id`, `name`, plus `disconnect`, `subscribe` and `switchChain` when the wallet supports them. |
| `resolveAccount(account?)` | The Wallet Standard account a call signs with; throws for an account the wallet does not expose.                                                                      |
| `resolveChainId(chain?)`   | The chain id a call targets; throws for a chain outside the namespace or not advertised.                                                                              |
| `currentChain()`           | The active chain, for results that build their own `Account`.                                                                                                         |

```ts
import type { SvmAdapter } from "@usebutr/core";
import { SVM_CHAINS_LIST } from "@usebutr/core";
import type { WalletStandardWallet } from "@usebutr/wallet-standard-shared";
import { createWalletStandardCore, slugify } from "@usebutr/wallet-standard-shared";

export const buildAdapter = (wallet: WalletStandardWallet): SvmAdapter | null => {
  const core = createWalletStandardCore({
    chains: SVM_CHAINS_LIST,
    id: slugify("svm", wallet.name),
    label: "Solana",
    namespace: "solana",
    preferredChainIds: ["solana:mainnet"],
    trackChainChanges: true,
    wallet,
  });
  // Add platform methods only when the wallet advertises their feature,
  // routing `options.account` through `core.resolveAccount` and
  // `options.chain` through `core.resolveChainId`.
  return core === null ? null : { ...core.base, chainPlatform: "svm" };
};
```

### `discoverWalletStandard(onAdapter, build, loadModule?): () => void`

Loads the registry, builds an adapter for each registered wallet with
`build`, announces each id once, and bridges `unregister` into a
`disconnected` event. A missing `@wallet-standard/app` logs one warning and
disables this source. `WalletStandardAdapterBuilder` is
`(wallet, registerDisconnector) => WalletAdapter | null`.
